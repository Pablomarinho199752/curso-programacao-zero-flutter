# Módulo 0 — Começando do absoluto zero

Objetivo: construir a base mental antes de introduzir muitos comandos.

## Aula 0.1 — O que é programar?

Já implementada na v0.1 do app.

Fluxo: explicação curta → videoaula → exemplo → prática → desafio → 3 perguntas → revisão.

## Próximos conteúdos do Módulo 0

Serão definidos e produzidos progressivamente após validar a Aula 0.1. A próxima aula só entra quando houver clareza sobre o que o aluno entendeu e onde teve dificuldade.

## Critério para sair do Módulo 0

O aluno deverá conseguir:

- explicar com palavras próprias o que é algoritmo, código e programa;
- executar e modificar um programa simples;
- prever saídas simples antes de executar;
- ler uma mensagem de erro básica sem entrar em pânico;
- tentar corrigir uma pequena falha usando pistas.
