Um pedido, três informações

DADOS DO PEDIDO
produto → Suco
quantidade → 2
preco → 4.5
IDEIA PRINCIPAL
Dar nomes ajuda a encontrar e reutilizar dados.

Título: Variáveis: nomes para os dados. Cartão de pedido de lanchonete: Suco / 2 / 4.5. Um dado por vez, sem código ainda.

Ler narração planejada

Imagine que você está organizando um pedido numa lanchonete. Você precisa lembrar qual é o produto, quantas unidades foram pedidas e o preço de cada uma. São três informações diferentes. Como dar um nome para cada informação, para o programa conseguir usá-la depois? É isso que vamos descobrir. Nesta aula, o foco é um só: entender a diferença entre o nome de uma variável e o valor associado a ela.

CÓDIGO ZERO AULA 1.1 · CENA 2/7

Nome e valor são coisas diferentes

PYTHON · DEMONSTRAÇÃO
produto = "Suco"
IDEIA PRINCIPAL
Nome → valor
Atribuição: direita para esquerda

Editor grande: produto = "Suco". Cursor aponta produto; depois =; depois "Suco". Diagrama etiqueta produto → valor "Suco".

Ler narração planejada

Vamos escrever a primeira linha. Produto recebe o texto Suco. À esquerda, produto é o nome que escolhemos. À direita, Suco é o valor. O sinal de igual faz a atribuição: associa o valor da direita ao nome da esquerda. Pense numa etiqueta que permite encontrar uma informação. A etiqueta não é a informação em si. As aspas mostram que Suco é um texto. Elas fazem parte da escrita do código, mas não fazem parte do texto que vamos mostrar.

Texto, inteiro e decimal

PYTHON · DEMONSTRAÇÃO
produto = "Suco"
quantidade = 2
preco = 4.5
IDEIA PRINCIPAL
Texto: aspas
Decimal: ponto

Código aparece linha a linha: produto = "Suco" / quantidade = 2 / preco = 4.5. Realçar textos ciano e números lilás; não depender só da cor. Rótulos texto / inteiro / decimal.

Ler narração planejada

Agora acrescentamos quantidade recebe dois, e preco recebe quatro ponto cinco. Quantidade está associada a um número inteiro. Preco está associado a um número decimal. Em Python, escrevemos esse decimal com ponto. Texto fica entre aspas; nestes exemplos, os números ficam sem aspas. Escolhemos nomes que contam o que o dado representa. Isso ajuda a ler o programa e, mais tarde, a encontrar problemas. Até aqui, demos nomes aos dados. Ainda não pedimos para mostrar nada.

Acrescentar print(produto), print(quantidade), print(preco). Mostrar clique do cursor em Executar e painel Saída: Suco / 2 / 4.5. Rotular “Demonstração — saída conferida em Python”. Reservar 3s de previsão antes do clique.

Ler narração planejada

Para ver os valores, usamos print, que você já conheceu. Dentro dos parênteses, colocamos o nome que queremos consultar. Antes de executar, tente prever: a primeira linha da saída vai mostrar produto ou Suco? Pense por um instante. Agora executamos. Aparece Suco, depois dois, depois quatro ponto cinco. Print consultou cada nome e mostrou o valor associado a ele. Repare na separação: em cima está o código que escrevemos; embaixo está a saída produzida ao executar.

CÓDIGO ZERO AULA 1.1 · CENA 5/7

As aspas mudam a instrução

PYTHON · DEMONSTRAÇÃO
produto = "Suco"
print("produto")
print(produto)
SAÍDA CONFERIDA EM PYTHON
produto
Suco

Editor novo: produto = "Suco" / print("produto") / print(produto). Clique Executar, saída produto / Suco. Zoom no par de aspas da segunda linha e comparação lado a lado.

Ler narração planejada

Vamos comparar duas linhas quase iguais. Na primeira, print recebe a palavra produto entre aspas. Na segunda, recebe produto sem aspas. Execute e observe: primeiro aparece a palavra produto; depois aparece Suco. Com aspas, pedimos para mostrar aquele texto literalmente. Sem aspas, pedimos para consultar o nome da variável. Um detalhe pequeno muda a instrução. Se a saída não for a que você esperava, conferir essas aspas é um bom começo.

CÓDIGO ZERO AULA 1.1 · CENA 6/7

Um erro é uma pista

PYTHON · DEMONSTRAÇÃO
produto = "Suco"
print(Produto)
SAÍDA CONFERIDA EM PYTHON
Linha 2
NameError: name 'Produto' is not defined.

Editor: produto = "Suco" / print(Produto). Clique Executar, mostrar linha 2 e NameError: name 'Produto' is not defined. Pausa 3s; zoom alinhado produto vs Produto; corrigir só P para p, clicar Executar; saída Suco.

Ler narração planejada

Agora vou colocar um erro de propósito. Criei produto com p minúsculo, mas escrevi Produto com p maiúsculo dentro do print. Ao executar, aparece NameError: esse nome não foi definido. Não precisamos apagar tudo. Primeiro, olhamos a linha indicada: a linha dois. Depois perguntamos: o nome que estou usando é exatamente igual ao que criei? Compare letra por letra. Aqui está a diferença. Python distingue maiúsculas de minúsculas. Vamos mudar apenas o P para p e executar de novo. Agora aparece Suco. Fizemos uma hipótese, uma mudança pequena e um novo teste para conferir.
