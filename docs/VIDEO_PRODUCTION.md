## Observação sobre os módulos 3–12

As tentativas de renderização pelo HeyGen falharam por falta de créditos `unlimited_regular`. Para não travar o curso nem consumir os poucos créditos generativos restantes, os módulos 3–12 receberam uma versão didática narrada produzida no sandbox: telas 16:9 com identidade visual do Código Zero, exemplos de código e narração em português. Esses vídeos são materiais reais e reproduzíveis, mas não devem ser descritos como animações generativas ou vídeos de avatar do Higgsfield.

No futuro, cada um pode ser substituído por uma versão audiovisual mais rica sem alterar a estrutura pedagógica ou o progresso do aluno: basta trocar a URL correspondente em `assets/content/video_urls.json`.

## Regra para integração

Um vídeo só recebe URL definitiva no aplicativo quando existe uma URL pública/estável adequada para o aluno. Identificador de renderização, URL assinada temporária ou tela interna do provedor não é tratada como link final.
