# Versões de videoaulas

A aba **Vídeos** de cada aula apresenta o vídeo original e, quando existe um link novo e diferente, a **Nova versão**. Ambos ensinam o mesmo conteúdo e compartilham o progresso da aula.

Os links originais permanecem no conteúdo das aulas. Os links novos vêm de `assets/content/video_urls.json`. O aplicativo não substitui nem reencoda vídeos.

Verificar no build Android/Windows: abertura de ambos os links, fallback quando não existe versão nova e preservação do progresso da aula.
