# Mapa Mestre do Curso

O curso é adaptativo: o aluno não avança apenas por concluir telas. O avanço depende de domínio demonstrado.

| Etapa | Tema | Projeto principal | Critério de domínio |
|---|---|---|---|
| 0 | Começando do absoluto zero | Primeiro programa interativo | Executar, alterar e explicar programas simples |
| 1 | Fundamentos | Calculadora inteligente | Transformar entrada, processamento e saída em código |
| 2 | Decisões | Sistema de regras | Criar decisões com várias condições |
| 3 | Repetições | Jogo de adivinhação | Reconhecer quando usar repetição |
| 4 | Coleções e textos | Cadastro em memória | Escolher estruturas adequadas |
| 5 | Funções | Programa modular | Dividir problemas em partes reutilizáveis |
| 6 | Arquivos, erros e módulos | Gerenciador persistente | Salvar dados e lidar com falhas |
| 7 | Debugging e qualidade | Hospital de códigos | Encontrar causas de bugs |
| 8 | APIs | Aplicação com serviço externo | Ler documentação e integrar uma API |
| 9 | Banco de dados | Estoque ou financeiro | Implementar CRUD persistente |
| 10 | Estrutura de projetos | Aplicação organizada | Estruturar projeto em arquivos e camadas |
| 11 | Git e GitHub | Portfólio versionado | Trabalhar com commits, README e histórico |
| 12 | Independência | Projeto final | Planejar, construir, testar e pesquisar sozinho |

## Estados de domínio

- 🟢 Domina
- 🟡 Em desenvolvimento
- 🔴 Ainda não domina

## Regra de produção

O mapa é completo, mas as aulas são produzidas **um módulo por vez**, conforme o desempenho real do aluno.
